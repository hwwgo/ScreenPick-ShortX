# 屏幕取字 · ShortX 脚本

一根手指拖着一个悬浮箭头，**指到哪、取到哪**。取字、按词挑选、框选截图、保存或分享，都在同一个 ShortX 剧本里完成。

仓库有两个版本，用法相近，侧重不同：

| 版本 | 一句话 |
|---|---|
| **v7.80** | 取完字先弹**选字面板**：按词挑、按字挑，再复制；截图可保存 / 分享 |
| **v7.33.11** | 取完字**直接进剪贴板**；截图自动 OCR + 存相册；轻、快、没有面板 |

> 只支持 ShortX 运行环境，脚本不注册触发方式，导入后需要自己在 ShortX 里绑手势 / 磁贴 / 悬浮球。安装步骤见文末。

## 三十秒上手

| 想做什么 | 怎么做 |
|---|---|
| 取字 | 把箭头拖到文字上，松手 |
| 只取一个词（v7.80） | 面板里点那个词 → 点「复制」 |
| 框选一块区域 | 箭头**停住 1.5 秒**进入框选 → 拖出范围 → 松手 |
| 不要框选了 | 拖过选区后**停手 1.5 秒**，自动退回取字 |
| 整个不要了 | 任意时刻**第二根手指按下** |

两版共用的手感：

- 箭头贴到屏幕右 / 下边缘 53dp 以内会**自动加速**，方便指到最边上
- **悬停 1.5 秒**进框选，**框选内停手 1.5 秒**退回取字
- **第二指**随时取消
- 单实例防护：不会同时跑出两个箭头

## v7.80：先挑词，再复制

### 取字

箭头拖到文字上松手 → 弹出选字面板。面板按 **ICU 中文分词**切块，**一个词一块**；切不出词的机器会退回按字切，单块最多 12 字。

### 选字面板怎么用

| 操作 | 结果 |
|---|---|
| 点一个词块 | 选中；再点一次取消 |
| 按住拖动 | 连续加选 |
| 已选 ≥ 2 块，按在已选块上拖 | 区间**反选** |
| 拖到文字区上 / 下边缘 | 自动跟着滚 |
| 按在空白处上下拖 | 滚动；水平拖不动 |
| 「词 / 字」 | 在分词和按字之间切换 |
| 「清空 / 全选」 | 有选中时显示「清空」，没选中时显示「全选」 |
| 「复制」 | 选中才亮；点后文字进剪贴板并关面板 |
| 点面板外 / 第二指 | 关闭面板，不产生结果 |

**面板不会无操作自动关闭**，可以慢慢挑；只有挂死时才有 30 分钟的硬上限兜底。

### 截图面板

框选松手后先截图、再识别文字，弹出带**缩略图**的面板：

| 按钮 | 作用 |
|---|---|
| 「复制」 | 把选中的文字写进剪贴板 |
| 「保存」 | 只把截图存进 `DCIM/Screenshots` |
| 「分享」 | 存图后拉起系统分享面板 |
| 「取消」 / 点面板外 | 丢弃这张图 |

几个细节：

- **不按保存 / 分享就不落盘**；取消会直接删掉临时图
- 识别较慢时，**点一下屏幕可以跳过识别**，只存图
- 完全识别不到文字时，也会直接把图存进相册

### 其他

- 脚本本身**不弹吐司**，所有提示交给 ShortX 动作链，界面更干净
- 截图保存 / 分享需要 root（`su`）

## v7.33.11：取到就用

### 取字

箭头拖到文字上松手 → 文字**直接写进剪贴板**，吐司显示取到的内容。没有面板、没有二次确认。

### 框选截图

- 箭头**停住 1.5 秒** → 进入框选（箭头变选框）
- 拖出范围，**松手** → 截图 → 识别选区文字 → 写剪贴板 → **自动存进相册**
- 框选并拖过之后**停手 1.5 秒** → 静默退回取字
- 第二指 → 取消，吐司「用户取消」

### 特点

- 路径最短：取到即用，适合频繁摘字
- 体积小：导入文件 241 KB（v7.80 是 403 KB）
- 没有选字面板，也不支持分享截图
- 截图后自动落盘；归档命令写死了 ShortX 实例目录，**重装 ShortX 后要改路径**

## 安装

1. 选一个版本下载：
   - v7.80：`dist/v7.80/屏幕取字_V7.80_ShortX导入.txt`
   - v7.33.11：`dist/v7.33.11/屏幕取字_V7.33.11_ShortX导入.txt`
2. 传到手机，ShortX → 剧本列表 → **导入** → 选择该 txt。
3. 同名「屏幕取字」选择**覆盖安装**。
4. 授予**无障碍 / UiAutomation** 权限；框选另需**截图**权限。
5. 给剧本绑定触发方式。

> 两版共用同一个 `id` 和标题，**一台手机只能装一个**，后导入的会覆盖前一个。

截图保存 / 分享需要 root；没有 root 也能取字和框选，只是图会留在 ShortX 私有目录。

## 常见问题

**取不到字？**
a11y 拿不到节点的页面（云闪付、游戏、部分 Canvas）会自动走 OCR，需要 ShortX 的 OCR 可用。

**v7.80 词切得很粗，一块好几个字？**
看 `Download/屏幕取字_probe.log` 里的 `PANEL_SEG`：`src=icu` 是正常分词，`src=char` 表示这台机器没起来中文词典，退回了按字切。

**截图没进相册？**
先确认给了 root。v7.33.11 还要确认 ShortX 实例目录没变（命令里写死了 `shortx_<后缀>`），v7.80 用通配目录，不受影响。

**分享点了没反应？**
需要 root；部分 ROM（如 ColorOS）还要允许 ShortX 后台启动。
