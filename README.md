# 屏幕取字 · ShortX 脚本

一根手指拖着一个悬浮箭头，**指到哪、取到哪**。取字、按词挑选、框选截图、保存或分享，都在同一个 ShortX 剧本里完成。

仓库有两个版本，用法相近、侧重不同；`dist/v7.80/` ~ `dist/v7.88/` 是 v7.89 的历史版本，只留作回退。

| 版本 | 一句话 |
|---|---|
| **v7.89** | 取完字先弹**选字面板**：按词挑、按字挑，再复制；截图可保存 / 分享；**截图里的二维码能解成原文**，解出来的字和 OCR 文字**同一套字块**（同字号、同底色、同拆法），只隔一条横线。取字模式不碰二维码。OCR 走快速档 |
| **v7.33.11** | 取完字**直接进剪贴板**；截图自动 OCR + 存相册；轻、快、没有面板 |

> 只支持 ShortX 运行环境，脚本不注册触发方式，导入后需要自己在 ShortX 里绑手势 / 磁贴 / 悬浮球。安装步骤见文末。

---

## 三十秒上手

| 想做什么 | 怎么做 |
|---|---|
| 取字 | 把箭头拖到文字上，松手 |
| 只取一个词（v7.89） | 面板里点那个词 → 点「复制」 |
| 框选一块区域 | 箭头**停住 1.5 秒**进入框选 → 拖出范围 → 松手 |
| 不要框选了 | 拖过选区后**停手 1.5 秒**，自动退回取字 |
| 整个不要了 | 任意时刻**第二根手指按下** |

两版共用的手感：

- 箭头贴到屏幕右 / 下边缘 53dp 以内会**自动加速**，方便指到最边上
- **悬停 1.5 秒**进框选，**框选内停手 1.5 秒**退回取字
- **第二指**随时取消
- 单实例防护：不会同时跑出两个箭头

## v7.89：先挑词，再复制

### 取字

箭头拖到文字上松手 → 弹出选字面板。面板按 **ICU 中文分词**切块，**一个词一块**；切不出词的机器会退回按字切，单块最多 12 字。

### 选字面板怎么用

| 操作 | 结果 |
|---|---|
| 点一个词块 | 选中；再点一次取消 |
| 按住拖动 | 连续加选 |
| 已选 ≥ 2 块，按在已选块上拖 | 区间**反选** |
| 拖到文字区上 / 下边缘 | 自动跟着滚 |
| 按在空白处上下拖 | 滚动；水平拖不动 |
| 快速划一下松手 | 内容**继续滑一段再慢慢停**（惯性）；慢慢拖不会滑 |
| 滑行中再按住 | 立刻停住，可以接着选字 |
| 屏上有二维码 | 面板中间多一层「二维码内容」；点那一层或提示行的「复制码」，**整段**进剪贴板 |
| 「词 / 字」 | 在分词和按字之间切换 |
| 「清空 / 全选」 | 有选中时显示「清空」，没选中时显示「全选」 |
| 「复制」 | 选中才亮；点后文字进剪贴板并关面板 |
| 点面板外 / 第二指 | 关闭面板，不产生结果 |

**面板不会无操作自动关闭**，可以慢慢挑；只有挂死时才有 30 分钟的硬上限兜底。

「取消 / 清空 / 复制」这组按钮贴在面板**右下角**，左下角单独留给「词 / 字」开关；
截图面板的按钮行也是同一条基线，两者手感一致。

### 截图面板

框选松手后先截图、再识别文字，弹出带**缩略图**的面板：

| 按钮 | 作用 |
|---|---|
| 「复制」 | 把选中的文字写进剪贴板 |
| 「保存」 | 只把截图存进 `DCIM/Screenshots` |
| 「分享」 | 存图后拉起系统分享面板 |
| 「取消」 / 点面板外 | 丢弃这张图 |

几个细节：

- **不按保存 / 分享就不落盘**；取消会直接删掉临时图
- 识别较慢时，**点一下屏幕可以跳过识别**，只存图
- 完全识别不到文字时，也会直接把图存进相册

### 其他

- 脚本本身**不弹吐司**，所有提示交给 ShortX 动作链，界面更干净
- 截图保存 / 分享需要 root（`su`）

## v7.33.11：取到就用

### 取字

箭头拖到文字上松手 → 文字**直接写进剪贴板**，吐司显示取到的内容。没有面板、没有二次确认。

### 框选截图

- 箭头**停住 1.5 秒** → 进入框选（箭头变选框）
- 拖出范围，**松手** → 截图 → 识别选区文字 → 写剪贴板 → **自动存进相册**
- 框选并拖过之后**停手 1.5 秒** → 静默退回取字
- 第二指 → 取消，吐司「用户取消」

### 特点

- 路径最短：取到即用，适合频繁摘字
- 体积小：导入文件 241 KB（v7.89 是 450 KB）
- 没有选字面板，也不支持分享截图
- 截图后自动落盘；归档命令写死了 ShortX 实例目录，**重装 ShortX 后要改路径**

## 安装

1. 选一个版本下载：
   - v7.89：`dist/v7.89/屏幕取字_V7.89_ShortX导入.txt`
   - v7.33.11：`dist/v7.33.11/屏幕取字_V7.33.11_ShortX导入.txt`
2. 传到手机，ShortX → 剧本列表 → **导入** → 选择该 txt。
3. 同名「屏幕取字」选择**覆盖安装**。
4. 授予**无障碍 / UiAutomation** 权限；框选另需**截图**权限。
5. 给剧本绑定触发方式。

> 两版共用同一个 `id` 和标题，**一台手机只能装一个**，后导入的会覆盖前一个。

`dist/v7.80/` ~ `dist/v7.88/` 保留着历史版本，功能与 v7.89 相同
（按钮位置、取字模式 OCR 兜底实现、OCR 输入图尺寸、滚动有没有惯性、
二维码扫不扫、面板分不分层、码层长什么样不同）。没有特别理由就用 v7.89。

截图保存 / 分享需要 root；没有 root 也能取字和框选，只是图会留在 ShortX 私有目录。

## 常见问题

**取不到字？**
a11y 拿不到节点的页面（云闪付、游戏、部分 Canvas）会自动走 OCR，需要 ShortX 的 OCR 可用。

**v7.89 词切得很粗，一块好几个字？**
看 `Download/屏幕取字_probe.log` 里的 `PANEL_SEG`：`src=icu` 是正常分词，`src=char` 表示这台机器没起来中文词典，退回了按字切。

**截图没进相册？**
先确认给了 root。v7.33.11 还要确认 ShortX 实例目录没变（命令里写死了 `shortx_<后缀>`），v7.89 用通配目录，不受影响。

**二维码扫不出来？（v7.89 起只有截图模式扫）**
先确认是**框选截图**取到的面板 —— 取字模式（指针指字）不解码，日志里也不该有
`QR_DIAG` / `AREA_QR_TRY`，那是正常的。截图模式看 `屏幕取字_probe.log`：
`AREA_QR_TRY ocr=41` → `AREA_QR_DONE ms=232 len=38`。`len=0` 才是「扫了没解出」，
一条都没有说明装的是旧版或 `qrScan` 被设成 `false`。
屏上码很小、模块糊在一起时，框得紧一点（框选原图不缩放，比整屏图清楚得多）；
`AREA_QR_FAIL` 说明扫码抛了异常，OCR 与面板不受影响。

**面板里的二维码怎么选？（v7.88 起，v7.89 只出现在截图面板）**
码文字就是普通的字块，点一块选一块、也能拖选；**在码层空白处点一下 = 整段码全选**，
再点「复制」就是码原文。码层默认最多显示 3 行高，超出**在码层里上下滑**（不截断）。
嫌矮就调 `qrPaneLines`（最多 6）；整层都不想要就设 `qrPane: false`。

**取字模式下指针指在二维码上，怎么没有黄框？**
v7.89 起取字模式**完全不碰二维码**，和 V7.84 一样 —— 不扫、不出框、也不会把码当文字塞进结果。
原因是硬约束：黄框来自 OCR 切出的字块矩形，二维码不会被 OCR 认成文字；
而 `ParseQRCode` 只回文本、不回坐标，脚本拿不到码的位置。
取码请用**截图模式**：框一下，码就出现在面板中间那层。

**框一段纯文字也慢了 0.3 秒？（v7.86 起）**
截图模式默认每次都扫二维码，大图解码要 200~400 ms（后台线程，不挡面板）。
如果从来用不到码，把 `qrScan` 设 `false`，截图流程立刻回到 V7.84 的速度。

**扫出来只有一串网址，没有正文？（v7.85 起）**
二维码里编码的就是那串原文（URL / WiFi / vCard）。要网页正文得再下载网页，
脚本不做这件事。解出来的链接**只复制、不自动打开**。

**取字时 OCR 有点慢，想更快？（v7.83 起）**
`ocrMaxSide` 默认 1024。改成 900 还能再快一截，代价是小字更容易认错；
反过来想要更清楚就改 1200 或 1440。改完看 `屏幕取字_probe.log` 里
`OCR_DIAG` 的 `cap=` 与 `ocr=` 两项即可对比。

**滚动滑得太远 / 太短？（v7.84 起）**
`panelFlingFriction` 默认 0.998，调小（如 0.996）收得更快，调大（如 0.9995）滑得更远；
`panelFlingMinV` 是起滑门槛，调大就要划得更快才会滑。把 `panelFling` 设 `false` 就退回
「抬手即停」。探针里有 `PANEL_FLING start/END`，能看到每次滑了多远、多久。

**图片里的字取不到、不出黄框？（v7.82 起）**
看 `Download/屏幕取字_probe.log` 里的 `OCR_DIAG` 一行：
`stage=ocr` 且 `blocks=0` 是截到空图；`stage=shot` 是截图就失败了（后面带 `err=`）；
`json=0` 是 OCR 结果没读出来（`keys=` 会列出真实字段名）；有 `blocks` 但
`OCR_HIT hit=0` 说明块坐标和指针坐标不在一个坐标系。

**分享点了没反应？**
需要 root；部分 ROM（如 ColorOS）还要允许 ShortX 后台启动。
