# 屏幕取字 v7.84 · ShortX 导入包

- **versionCode**：112
- **日期**：2026-11-14
- **形态**：ShortX ExecuteJS 剧本（单文件 ES5，无第三方依赖）

词/字双模式的选字面板：取字或框选后先挑词，再复制、保存或分享。
这一版只做一件事：**选字框空白处拖动加惯性** —— 快速划一下松手，文字继续
滑、越滑越慢直到停住；慢慢拖、拖到头、抬手前先停住都不会自己跑。OCR、截图、
分词、命中与交付内容全部与 v7.83 一致。

> 只支持 ShortX 运行环境；脚本调用 `shortx.getUiAutomation()`、`shortx.getShortXDir()` 与 ShortX 的 OCR 类。

---

## 安装

1. 把 `dist/v7.84/屏幕取字_V7.84_ShortX导入.txt` 传到手机。
2. ShortX → 剧本列表 → **导入** → 选择该 txt。
3. 同名「屏幕取字」选择**覆盖安装**（versionCode 112）。
4. 授予**无障碍 / UiAutomation** 与**截图**权限。
5. 给剧本绑定触发方式（手势 / 磁贴 / 悬浮球 / 长按）。

几个发行版（v7.33.11、v7.80 ~ v7.84）共用同一个 `id` 和标题，
**只能装一个**；后导入的会覆盖前一个。

## 使用

| 操作 | 结果 |
|---|---|
| 拖动指针到文字上，松手 | 弹选字面板 |
| 按住不动 1.5 秒 | 进入框选模式 |
| 框选内停手 1.5 秒 | 退回取字，不再框选 |
| 框选后松手 | 截图 → OCR → 弹面板（带缩略图） |
| 第二根手指按下 | 取消本次操作 |
| 点词块 / 在已选块上拖 | 加选 / 区间反选 |
| 空白处上下拖 | 滚动文字区 |
| 快速划一下松手 | 继续滑一段再慢慢停（惯性） |
| 滑行中按住 | 立刻停住 |
| 「词/字」 | ICU 分词 / 按字切块 |
| 「清空 / 全选」 | 有选中显示「清空」，否则「全选」 |
| 「复制」 | 选中才亮，复制并关闭 |
| 「保存」「分享」 | 仅截图模式，存 DCIM / 拉起系统分享 |

面板不会无操作自动关闭，只有 30 分钟的挂死兜底。

## 这一版改了什么

选字框的空白处上下拖本来就是 1:1 跟手、抬手立刻定住。V7.46 当初不做惯性，
理由是"每一步都要重画 4MB 位图"；V7.47 起滚动只补文字区（单帧 2~4ms），
这条理由早就不成立了。

现在：手势期间记速度样本（只留最后 120ms），抬手时取窗口首尾差分得到手速；
超过 350px/s 才起滑，之后每 16ms 走一步、速度按 `friction^dt` 衰减
（帧率抖动不影响距离与时长），降到 50px/s 以下收尾。

四种情况**不会滑**：慢慢拖、抬手前手指先停住（>45ms）、拖到边界还在硬顶、
内容不足一屏。手指一按下、切换「词/字」、关面板，惯性立刻停。

滑太远 / 太短：改 `panelFlingFriction`（0.996 收得快，0.9995 滑得远）；
觉得太容易滑：调大 `panelFlingMinV`；想回到旧手感：`panelFling` 设 `false`。

探针日志里每次都有两行：

```text
PANEL_FLING start v=2.19 dir=up at=0/1576
PANEL_FLING_END why=slow v=0.04 dist=1244 ms=1968
```
