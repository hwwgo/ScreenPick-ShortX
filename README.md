# 屏幕取字 · ShortX 指针脚本

屏幕上一根悬浮箭头，压到哪里取哪里的字；指针停住片刻还能拉框截图。
纯 ShortX 脚本（`ExecuteJS`），不用另装 App，导入即用。

仓库里放了三个版本，功能深浅不同，**共用同一套交互和同一套取字通道**，
按需要挑一个就行。

## 共通之处

1. **同一套操作**：箭头常驻，按住拖动定位，松手取字；指针在原地停 1.5 秒自动进入框选；
   多指按下退出。
2. **同一套取字通道**：先读无障碍节点（a11y），读不到才截图走 OCR；OCR 结果带短记忆缓存，
   拖动时查询在后台线程跑，不卡指针。
3. **同一个交付协议**：脚本只返回 JSON（`ok` / `type` / `code` / `value` / `data`），
   写剪贴板、存相册、拉起分享都由 ShortX 指令链决定。
4. **同一套稳定性机制**：单实例防护、建窗 12 秒超时强制拆窗、300 秒全局看门狗。
5. **同一套指针手感**：箭头尖端跟手；距屏幕右缘 / 下缘 53dp 内渐变加速，长距离移动不用反复搓。
6. **同一个动作 id**：三个文件导入的是同一个 ShortX 动作，**后导入的会覆盖前一个**，
   不能共存；想同时留着，先在 ShortX 里把已有动作复制一份。
7. **同样的运行环境**：ShortX（Xposed）+ 无障碍服务；只有「存相册 / 分享」两个分支用到 `su`，
   取字本身不需要 root。

## 区别

| | V7.33.11 | V7.84 | V8.05 |
|---|---|---|---|
| **取字结果怎么给** | 抬手直接写剪贴板，并弹一条提示把文字回显出来 | 先弹选字面板，挑好再点「复制」 | 同 V7.84 |
| **选字面板** | 无 | 词 / 字两种粒度；连续滚动；空白处拖动带惯性 | 同 V7.84 |
| **二维码** | 无 | 无 | **有**：截图模式在面板中间加一层「码原文」；取字模式指针移到码上出黄框，抬手可复制原文 |
| **截图模式** | 一个分支：OCR 出字并复制，同时把图存进相册 | 三个分支：选字、存图、分享 | 同 V7.84 |
| **屏幕提示** | 有（失败 / 取消 / 识别已就绪 / 取到的文字） | 无，全程静默 | 无，全程静默 |
| **运行日志** | 不写任何文件 | 写 `屏幕取字_probe.log`（面板自愈、扫码诊断用） | 同 V7.84 |
| **OCR 输入** | 屏幕区域原图直喂 | 长边缩到 1024 再识别 | 同 V7.84 |
| **versionCode** | 50 | 112 | 133 |

三点补充：

- **V7.84 与 V8.05 的面板、截图三分支完全一样**，差别只在二维码。V8.05 体积更小，是因为发行版
  去了注释和缩进，面板能力一项没少。
- **V7.33.11 没有面板**：取完直接进剪贴板，只能靠提示回显确认；选错了得重新取。它的截图也
  只有一条路 —— 出字就复制、同时存相册，不能单独选「只存图」或「只分享」。
- **二维码只在 V8.05 有**：截图模式下它作为面板的一层出现（和 OCR 文字同一套字块，中间隔一条
  横线）；取字模式下指针压到码上才出黄框，抬手弹同一个面板。

## 怎么选

- 只想要「指哪复制哪」、设备较老或在意启动速度 → **V7.33.11**
- 经常要在一段话里挑几个词、几行字 → **V7.84**
- 需要认二维码，或者不想维护两套 → **V8.05**（面板能力与 V7.84 相同）

## 导入

1. ShortX → 动作 → 导入，选对应的 `.txt`（文件尾部自带 `###------###` 与 `{"type":"da"}`，不要手工改）。
2. 给 ShortX 开无障碍服务；第一次运行时按提示授予截图权限。
3. 运行该动作，箭头出现即生效；再次运行同一动作会先拆掉旧的再建新的。

> 菜单名称以你装的 ShortX 版本为准。三个文件导入后是同一个动作，覆盖关系见「共通之处」第 6 条。

## 打包

把三个版本打成一个 zip（发 Release 用）：

```bash
./tools/pack.sh            # → dist/ScreenPick-ShortX-<UTC 日期>.zip
./tools/pack.sh v1.0       # → dist/ScreenPick-ShortX-v1.0.zip
```

包内平铺三个 `.txt` + 本 README，另生成 `dist/SHA256SUMS.txt`。
依赖 `bash` + `zip`；Windows 在 Git Bash 或 WSL 里跑。
