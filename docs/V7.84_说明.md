# V7.84 说明：选字框拖动的惯性

**一句话**：选字框里按住空白往上快速一划、松手，文字继续往上滑，越滑越慢直到停住；慢慢拖、拖到头、抬手前先停住，都**不会**自己跑。

---

## 一、为什么 V7.46 没做，现在能做

V7.46 把分页改成连续滚动时，注释里写得很直白：

> 抬手即停（不做惯性：惯性要自己跑动画，每一步都得重画 4MB 位图，不值当）

当时的滚动是**整画**：每帧新建/擦除一张 1080×2400 的位图，再画一遍固定层（边框、标题、计数、按钮）。一帧 4 MB，60 帧就是 240 MB 的分配与绘制，主线程扛不住。

V7.47 起改成**双缓冲 + 只补文字区**：固定层不可能变（滚动只改 `scrollY`，不动选中态），所以拿背面那张已经画好的图，只重画文字区。单帧降到 2~4 ms，滚动帧间隔也从 60 ms 压到 10~16 ms。

也就是说：**惯性唯一的成本障碍，在七个版本前就没了**。剩下的是手感问题 —— 长文本里找一个词，划一下停一下，找一行要划七八次。

## 二、怎么做的

### 1. 采速度（MOVE 时顺手记）

滚动手势每走一步，记一条 `{时间, 手指 y}`，只留最近 24 条（约 120 ms）：

```js
d.vt.push({ t: tNow, y: ly });
if (d.vt.length > 24) d.vt.shift();
```

**顶到边界那一段不记**：`scrollTo` 返回 `false` 说明这一步没滚（已经在头/尾），把样本清空 —— 否则在已经到头的方向继续快速划、抬手，内容会朝空处白滑一下。

### 2. 算速度（抬手时）

取窗口内**最早一条 → 最新一条**的差分，而不是逐点平均：

```js
var v = (first.y - last.y) / dt;   // 手指上移（y 变小）→ 正 → 内容上滚
```

比逐点平均抗抖动，也比 `VelocityTracker` 的最小二乘便宜。三个提前退出：

| 情况 | 判据 | 为什么 |
|---|---|---|
| 样本不足 | `< 2` 条 | 分不清方向 |
| 抬手前手指停住 | 距最后一条 > 45 ms | 速度已经归零，不算"快速划一下" |
| 采样窗口太短 | `dt < 12 ms` | 一两个事件算出的速度不可信 |

### 3. 滑（每 16 ms 一帧）

```js
want = scrollY + v * dt;
v = v * Math.pow(friction, dt);   // 按真实经过时间衰减
```

按 `dt` 而不是"每帧乘一个固定系数"，是为了让帧间隔抖动（16 / 20 / 偶发 40 ms）不改变滑行距离和时长 —— 慢机上滑得一样远。

三个收尾条件，都会在 probe 里留一行 `PANEL_FLING_END why=…`：

| why | 含义 |
|---|---|
| `edge` | 撞到顶部或底部 |
| `slow` | 速度衰减到 50 px/s 以下（正常收尾） |
| `stuck` | 算了位移但 `scrollY` 没变（异常兜底） |
| `down` | 手指又按下了 |
| `layout` | 切换了「词 / 字」 |
| `detach` | 面板关了 |

## 三、实测滑行曲线

测试里模拟「5 步 × 16 ms，共 200 px」的快划（v₀ ≈ 3.1 px/ms），面板内容 600 块、可滚 1576 px：

| 时间 | 累计位移 |
|---|---|
| 100 ms | 222 px |
| 300 ms | 556 px |
| 500 ms | 799 px |
| 800 ms | 1013 px |
| 1200 ms | 1154 px |
| 1600 ms | 1217 px |
| 2000 ms | 1244 px（停） |

前 500 ms 走掉三分之二，后面越来越慢 —— 这就是"慢慢停止"的形状。总距离约等于文字区一屏多一点。

## 四、四种不起滑的情况

| 你的动作 | 结果 | 为什么 |
|---|---|---|
| 慢慢拖（< 350 px/s） | 抬手即停 | 慢慢拖的人在做精细定位，甩出去反而糟 |
| 划完停一下再抬手 | 抬手即停 | 手停住 = 意图已经表达完 |
| 拖到头还在硬划 | 抬手即停 | 那一段手速没产生位移，不算数 |
| 内容不足一屏 | 不可滚 | `maxScroll = 0`，本来就没得滑 |

## 五、自己调

全在配置段，改数字即可：

| 参数 | 默认 | 作用 |
|---|---|---|
| `panelFling` | `true` | 设 `false` 回到 V7.83 的"抬手即停" |
| `panelFlingMinV` | `0.35` | 起滑门槛（px/ms）。调大 = 要划更快才滑；调小 = 更容易滑 |
| `panelFlingFriction` | `0.998` | 每毫秒速度保留率。**调小停得快**（0.996 ≈ 一滑即停），调大滑得远（0.9995 很长） |
| `panelFlingMaxV` | `6.0` | 手速上限（px/ms），防止异常样本把内容甩飞 |
| `panelFlingStopV` | `0.05` | 衰减到这里收尾（px/ms） |
| `panelFlingFrame` | `16` | 惯性帧间隔（ms） |
| `panelFlingWindow` | `120` | 速度采样窗口（ms） |

探针日志里能看到每次的实际表现：

```
PANEL_FLING start v=2.19 dir=up at=0/1576
PANEL_FLING_END why=slow v=0.04 dist=1244 ms=1968
```

`dist` 太远就调小 `panelFlingFriction`，`start` 出现得太频繁（轻轻一划就滑）就调大 `panelFlingMinV`。
