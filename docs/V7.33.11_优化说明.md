# V7.33.11 优化说明（基于 V7.33.10）

> 一句话：**加速区收到 53dp（-1/3）、删掉分析与日志设施、清掉死参数链路，母版从 296KB 降到 221KB（-25.4%）。**

---

## 一、边缘加速区缩小 1/3

| 项 | 上一版 | 本版 |
|---|---|---|
| `edgeAccelDist` | `dp(80)` | **`dp(53)`**（80 × 2/3 ≈ 53） |
| `edgeAccelGain` | 0.45 | 0.45（不变） |
| 加速起点（手指距右/下缘） | 80dp | **53dp** |

也就是说：手指离边 **53dp 以外完全不加速**（1:1 跟手，方便精细定位）；进到 53dp 内才开始"手指 1 格、箭头约 1.7 格"，越靠边越快。取字与框选共用 `effectiveOffset`，两边手感一致。

### 实测（右缘，3x 屏，单位 dp）

| 手指距边 | 无加速 | 上一版 80dp | 本版 53dp |
|---|---|---|---|
| 70 | 82.0 | 77.0 | **82.0**（不加速） |
| 60 | 69.0 | 60.0 | **69.0**（不加速） |
| 53 | 60.0 | 48.0 | **60.0**（起点） |
| 50 | 56.0 | 42.0 | 55.0 |
| 40 | 44.0 | 26.0 | 38.0 |
| 30 | 32.0 | 9.0 | 22.0 |
| 22 | 23.0 | -3.0 | 9.0 |
| 15 | 16.0 | -13.0 | **-1.0（贴边）** |

区中段（50→40）位移增益 **1.70×**；上一版同段约 1.9×，因为加速区更长、累计加量更多。

要再调：`edgeAccelDist` 改 `dp(40)`（更短更轻）或 `dp(64)`（更接近上一版）；`edgeAccelGain` 控制强度，0.35 更淡、0.6 更明显。

## 三、死参数链路清理（每次查询少一次分配）

`findBestNode` 的 `selfRect`、`hitRadius` 两个形参**从未被使用**（只出现在签名和一句注释里），但每次查询仍会：

- `new android.graphics.Rect()` 一次；
- `pointer.getLocationOnScreen()` 一次（跨进程 IPC）。

这条参数被 `queryAt → scheduleMemoRevalidate → lookupAtAsync` 一路传递，本次全链路删除：

```js
// 之前
findBestNode(activeRoot, x, y, selfRect, this.hitRadius, maxArea, ...)
queryAt(x, y, selfRect, force, noMemo)
lookupAtAsync(x, y, selfRect, onDone)

// 现在
findBestNode(activeRoot, x, y, maxArea, ...)
queryAt(x, y, force, noMemo)
lookupAtAsync(x, y, onDone)
```

`app.selfRect` 函数随之删除（已无调用者）。拖动时约 10~12 次/秒的查询，即每秒少 10~12 次 Rect 分配与 IPC。

## 四、体积

| 文件 | V7.33.10 | V7.33.11 | 变化 |
|---|---|---|---|
| 母版脚本 | 5,185 行 / 296,191 字节 | **4,250 行 / 220,901 字节** | **-18.0% 行 / -25.4% 字节** |
| 导入文件 | 317,517 字节 | **241,156 字节** | -24.1% |

减下来的构成：

| 来源 | 约 |
|---|---|
| 头注重写（783 行分条复盘 → 98 行「机制速览 + 一行一版沿革」） | -60 KB |

头注改为四段速览（运行链路 / 查询模型 / 指针窗 / 框选 / OCR / 吐司 / 维护），**关键原理注释全部保留**（多指退出四信号、命中策略、块聚合判据、短记忆三态等）。原来代码里 57 处「头注第 N 条」引用已一并清除，不再有悬空指针。

## 六、兼容与复测

- **接口不变**：返回 JSON 结构、`type`、`code`、`data.toast` 与上一版一致；缺少 `data.diag`/`data.ocr` 不影响 SwitchCase（五个 case 只看 `ok`/`type`/`data.toast`）。
- **不再产生文件**：之前若在 Download 见过 `屏幕取字_诊断.txt`，可以删掉，本版不会再写。
- **复测四点**：
  1. 慢拖向右/下缘，**60dp 外应与手指 1:1**，进 50dp 内才开始"跑得比手指快"，约 15dp 处贴边；
  2. 取字模式与框选模式的手感应当一致（共用同一函数）；
  3. 悬停 1.5s 进框选、停止 1.5s 截图、第二指取消——行为不变；
  4. 桌面/微信取字（a11y）与云闪付类页面（OCR）都正常。
